# scRNAseqTanglesClustering

## Installation
- The main application is launched by running the src/main/java/main/Main.java file.
- Running the application requires Java and Maven.
- The program was tested on Java version 21 using IntelliJ.
- We also provide a Python file which the program use to support certain features. Installing Python is required if you wish to use the associated features in the application, but it is not required to run the main application.

## How to use
- The application contains a graphical user interface with various features.
- The framework contains a tangle based clustering pipeline. Different methods for various parts of the pipeline are available.
- It is possible to load a data set and test different configurations of the tangles based pipeline.
- It is also possible to load a folder containing multiple data sets for comparisons of multiple configurations.
